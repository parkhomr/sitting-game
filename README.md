# Oscar Farm Club — СИДИ КАЧАЙСЯ

A buildless, endless browser farming game featuring Oscar as a seated pixel-art Drow Ranger. All game art is drawn with Canvas; there are no image or game engine dependencies. Optional Google Fonts fall back to system fonts.

Serve `dist/` using any static web server. For example: `python3 -m http.server 8000 --directory dist`.

- Start with «СЕСТЬ И КАЧАТЬСЯ»; auto-farming is enabled by default.
- Click the forest or press Space for an extra arrow. Q fires five arrows, with a 12-second cooldown. P pauses.
- Spend creep gold on damage, attack speed, and experience upgrades.
- Creeps and waves never end. Oscar cannot die. Progress is saved locally in this browser, with a confirmation before reset.
- Sound is optional and off by default. Inactive browser tabs suspend gameplay; there is no offline simulation.

Unofficial Dota 2 fan project. Drow Ranger and Dota 2 belong to Valve.
